# Lab 2 - EC2 Startup Script (User Data Automation)

## Objective:

The goal of this lab is to introduce Linux automation and cloud initialization by writing a startup script that configures an EC2 instance to host a front-facing static website.
Using Bash scripting, an automated server will be setup without manual intervention!
